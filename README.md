# Leave Management System

A web-based Leave Management System
developed using Node.js, Express.js,
MongoDB and HTML, CSS, JavaScript.

## 🚀 Live Demo

[Click Here to View Live Project](https://leave-management-system-fs5r.onrender.com)

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas

## Features

- Student Registration and Login
- Staff Registration and Login
- Apply for Leave
- View Leave Balance
- View Leave History
- Staff Leave Approval and Rejection
